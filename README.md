## Compilación

**Compilador:** pdflatex

**Orden de comandos:**
```bash
pdflatex prueba_practica_unidad4.tex
pdflatex prueba_practica_unidad4.tex
```
(se compila dos veces para resolver correctamente las referencias cruzadas, numeración de figuras y tablas)

**Archivo principal:** `prueba_practica_unidad4.tex`

**Archivo de salida:** `prueba_practica_unidad4.pdf`

**Dependencias (paquetes LaTeX):**
- inputenc, fontenc, babel (spanish)
- amsmath, amssymb
- graphicx
- xcolor (opciones table, dvipsnames)
- array, tabularx, multirow, colortbl, booktabs, longtable
- enumitem
- microtype
- parskip
- titlesec
- fancyhdr
- caption
- pdflscape
- tcolorbox (opción most)
- float
- tikz (librerías: positioning, arrows.meta, shapes.geometric, shapes.multipart, calc)
- textcomp
- helvet

Todos estos paquetes están incluidos en distribuciones LaTeX completas como **TeX Live** o **MiKTeX**, por lo que no requieren instalación manual adicional.
